# ⛈️ TAF (Terminal Aerodrome Forecast)

TAF on sääennuste, joka kattaa tyypillisesti 9–30 tunnin ajanjakson lentoaseman lähialueella. Se on kriittinen työkalu lentosuunnittelussa ja polttoainelaskuissa, sillä se ennakoi tulevat olosuhteet.

Toisin kuin METAR, TAF sisältää usein muuttuvia ryhmiä (BECMG, TEMPO, PROBxx), jotka tekevät tulkinnasta monimutkaisempaa. Tämän osion tavoitteena on jäsentää nämä muutostrendit.

!!! abstract "Keskeinen ero METARiin"
    METAR on **havainto** (tieto nykyhetkestä), kun taas TAF on **ennuste** (tieto tulevasta).
